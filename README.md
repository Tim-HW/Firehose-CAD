# Firehose Assembly

This Firehose CAD has been 3D designed for Virtual reality application to simulate a real firehose.
This CAD can be completely 3D printed. If you power it with a Battery, Arduino with bluetooth and some potentiometer you can replicate the movement of such device inside a game engine.
You can find inside the repository the CAD from Solidworks as well as the .stl to print it.
